# 羽毛球空场 Chrome 插件

在 Chrome 中查看清华羽毛球空场，按球馆和开始时间筛选，定时发送桌面通知，并定位到官方预约页面。插件独立运行，不需要 Python、conda 或服务器。默认在官网手动登录，也可以选择开启自动登录。

这个目录可以独立复制到新的公开 Git 仓库。它不依赖父项目中的 Python 程序、`config.json`、服务器任务或本地运行目录。扩展使用 GPLv3，详见 [LICENSE](LICENSE)。

隐私、安全和贡献规则见 [PRIVACY.md](PRIVACY.md)、[SECURITY.md](SECURITY.md) 和 [CONTRIBUTING.md](CONTRIBUTING.md)。

## 安装

1. 使用桌面版 Chrome 120 或更新版本，Windows、macOS、Linux 均可。
2. 下载本项目后保留整个 `chrome-extension` 文件夹；如果使用打包的 `autobook-chrome-extension.zip`，先解压。
3. 在地址栏输入 `chrome://extensions`，打开右上角的「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择**包含 `manifest.json` 的 `chrome-extension` 文件夹**。
5. 在浏览器工具栏的扩展程序菜单中，把「羽毛球空场 · 清华」固定到工具栏。

这是本地加载的 Manifest V3 插件，尚未发布到 Chrome 应用商店。更新源文件后，在扩展管理页点击刷新，再重新打开插件和官网标签页。

## 首次登录和查询

1. 点击插件中的「去登录」或「打开官方登录」。
2. 在清华体育官网完成统一身份认证及官网要求的验证。
3. 返回插件，状态变为「已登录」。自动查询开启时，收到新的登录态会立即开始一次查询；也可以点击「立即查询」。
4. 查询过程中可以关闭插件弹窗。后台会继续查询，并保存结果。
5. 按日期查看结果，点击某一行的「去预约 ↗」，进入官方对应球馆页面。

插件会切换预约日期，滚动到目标场地并突出显示对应时间块。最后的场次选择、预约确认和支付都由你在官网完成。如果官网把可用小区间放在较大的时间块内，插件会突出显示包含该区间的时间块，并在提示条列出准确目标时段。如果场次已被别人预约、日期未开放或官网页面结构变化，会保留目标信息并提示你检查。

## 可选的自动登录

自动登录**默认关闭**。需要无人值守查询时，可以在插件的「自动登录」页启用。

1. 打开「开启自动登录」，填写统一身份认证账号、密码和 **Base32 格式的 TOTP 密钥**。密钥不是当前显示的六位动态码。
2. 点击「保存配置」，或点击「保存并登录」立即验证。首次开启时，Chrome 会请求允许插件在 `https://id.tsinghua.edu.cn/` 上运行登录脚本；拒绝授权时不会开启此功能。
3. 保存后，密码和密钥输入框保持为空，提示「已保存」。同一账号下留空表示保留原值，重新输入表示替换。更换账号时必须重新填写密码和密钥。
4. 查询发现 token 缺失、过期或被官网撤销时，插件会打开一个专用官网标签页，进入统一认证，填写账号密码，按需要选择 TOTP 并生成动态码。成功后自动关闭该标签页，接着执行空场查询。

「保存并登录」会执行一次登录和只读空场查询，即使自动查询开关处于关闭状态也可以使用。后台定时登录只由已开启的自动查询任务触发。关闭自动查询会停止当前登录尝试。

每次登录最多提交一次密码和一次 TOTP。官网认证失败、关闭登录标签页或两分钟超时后，会停止自动重试，并显示原因；检查配置或在官网处理额外验证后，点击「保存并登录」重试。出现其他验证方式时不会绕过验证。

关闭自动登录会保留本地凭据，方便下次启用。「清除已存凭据」会关闭自动登录，删除插件保存的账号、密码、密钥、token 和查询缓存；它不会退出官网自身的登录会话。第一次自动登录若官网直接沿用一个尚未核对身份的 SSO 会话，插件会要求先退出官网当前账号，再重试，避免使用错误账号。

TOTP 采用 30 秒周期、六位数字、HMAC-SHA-1，在插件后台通过 Web Crypto 生成，已用 [RFC 6238 标准测试向量](https://www.rfc-editor.org/rfc/rfc6238)校验。动态码临近过期时会等待下一个周期，电脑系统时间需保持准确。

## 筛选和通知

默认查询今天起四天内的四个羽毛球馆，每 30 分钟查询一次。

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 查询球馆 | 西体前馆、西体后馆、综体、气膜馆 | 支持多选，至少一个 |
| 工作日开始时间 | 16:00–23:59 | 根据预约日期判断周一至周五 |
| 周末开始时间 | 10:00–23:59 | 根据预约日期判断周六、周日 |
| 查询间隔 | 30 分钟 | 可设置为 5–1440 分钟的整数 |
| 自动查询 | 开启 | 关闭后取消定时查询，也会停止正在执行的查询 |
| 发现空场时通知 | 开启 | 每次成功查询有匹配空场时发送一次汇总通知 |

时间筛选依据**场次开始时间**，包含起止边界。比如 16:00–23:59 会保留 16:00 开始的场次。节假日仍按星期几判断；所有日期与时间按北京时间处理。已经开始的场次不显示。综体羽 6、7、13、14 **没有额外排除**。

保存设置后，下次查询使用新参数。缓存中已有的结果会立即按新筛选重新显示；刚勾选的球馆需要重新查询才能补齐。点击「立即查询」可以立刻应用。暂停自动查询时，仍可手动查询。

桌面通知点击后会打开完整的结果页。未启用通知时仍正常查询和更新结果。请在系统设置中允许 Chrome 通知，勿扰模式可能隐藏横幅。

## 登录态、隐私和运行边界

- 插件只从体育官网读取该账号的登录 token，保存在当前 Chrome 用户配置的扩展本地存储中；不会上传到第三方，也不会同步到其他 Chrome 设备。
- 默认不保存账号密码和 TOTP 密钥；开启自动登录后，用户填写的凭据保存在当前 Chrome 用户配置的扩展本地存储中，不使用云端同步。**本地存储未加密**，能读取该 Chrome 用户目录的人可能获得这些凭据。
- 设置页面不会回填已存密码或密钥，公共状态消息也不包含它们。登录脚本只能在插件当前创建的登录标签页、官方域名的顶层页面取得对应步骤所需的信息；TOTP 密钥不传给网页，只提交动态码。
- 安装包不包含项目的 `config.json`、`auth_state.json` 或 `token_cache.json`，也不读取邮件、Bark 或飞书配置。
- token 有有效期，也可能被官网提前撤销。关闭自动登录时需要自行重新登录；开启后插件会尝试官方认证流程，失败时提示人工处理。
- Chrome 必须处于运行状态。电脑休眠或浏览器退出时不保证按时查询，插件不会唤醒电脑；唤醒后由 Chrome 调度恢复。此行为来自 [Chrome alarms 生命周期规则](https://developer.chrome.com/docs/extensions/reference/api/alarms#concepts_and_usage)。
- 查询复用项目现有接口，按球馆/日期串行执行，组间等待 3 秒，避免官网限流。四个球馆、四天共 16 组，通常需要约一分钟，网络慢时会更久。超过总时限会提示重试。
- 接口失败、登录失效、查询被浏览器中断都会明确显示。部分失败只展示成功部分；全部失败会保留旧结果及原更新时间，不能把旧结果当作实时保证。
- 点击「去预约」不会锁场、提交预约、处理验证码或支付。可用状态以官网最后确认时为准。
- 插件的定时设置与服务器上的 Python 查询服务相互独立，修改插件不会修改 Linux cron 或手机 Bark 通知。

基础权限包含存储、定时器、桌面通知以及体育官网域名访问。自动登录额外使用可选的 `scripting` 和统一身份认证网站权限，仅在启用时请求，采用 [Chrome 可选权限机制](https://developer.chrome.com/docs/extensions/reference/api/permissions)。没有 `cookies`、`debugger`、`webRequest` 或全网站访问权限。普通内容脚本只在体育官网 `/venue/` 路径运行，自动登录脚本由后台注入当前登录任务的专用标签页。

## 开发和检查

不需要 npm 安装或前端构建，直接加载此目录即可。关键模块如下。

- `background.mjs` — 登录态接收、定时调度、查询状态和桌面通知。
- `lib/api.mjs` / `lib/signature.mjs` — 原有只读 API 请求及官方客户端签名协议。
- `lib/core.mjs` — 日期、筛选、空场解析和跳转地址。
- `content.js` — 官网登录态同步、日期切换与场次定位。
- `lib/auto-login.mjs` / `login-content.js` — 可选的官网自动登录、TOTP 计算、凭据访问范围和失败处理。
- `popup.html` / `popup.mjs` / `popup.css` — 结果列表和筛选设置。

接口签名常量来自现有官方网页客户端协议，不是用户账号凭据。扩展不加载远程 JavaScript，也不使用 `eval`。

在这个目录中运行逻辑测试（Node.js 22+）和重新打包（Python 3.9+）。父项目不需要参与扩展测试。

```bash
node --test tests/chrome_extension.test.mjs
python3 -m unittest discover -s tests -p 'test_release_check.py'
python3 scripts/check_release.py
python3 scripts/package_extension.py
```

打包脚本采用明确文件清单，只把插件运行文件、公开文档、许可证和图标打入 `dist/autobook-chrome-extension.zip`。测试、CI、脚本和本地文件不会进入安装包。

## 开源范围

本扩展只查询空场和定位官方预约页面。它不会自动点击场次、锁定场地、提交预约、创建订单、支付或绕过验证码。扩展依赖清华官方页面和接口，官方页面、接口、登录流程或访问策略变化时，扩展可能需要更新。
